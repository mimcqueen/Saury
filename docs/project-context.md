# Saury! — Project context (read first)

Steam / PC **3D Maury talk-show party game**: CPU Host, deadbeat minigames, **AI → 3D bowling-alley baby** after each win. Not Quiplash. Not phone-first.

## Locked product

- **Unity** · 6 creatures (Human, Goblin, Catgirl, Cryptid, Blob, Imp)
- **CPU Host** — everyone plays a dad; lobby owner still plays
- Local / simple Steam lobbies · soft **Gang Beasts–lite**
- Minis: white-trash / deadbeat (MVP: **Pissing Contest**, **Backyard BBQ Brawl**)
- Baby = **most fun part** — AI gen each win, selfie optional, 3D mesh + bowling-alley pomp
- Eerie dingy stage · eyes-only audience · spotlights · full VHS · wah + text (no real VO)
- Make Dad: attributes + mouse morph + Smooth/Pixel → feed baby gen
